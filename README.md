# Лабораторна робота №3 — Model Development

Розробка моделей для прогнозування ціни автомобіля (Automobile Data Set, UCI).

- Проста лінійна регресія (SLR), графіки регресії та залишків
- Множинна лінійна регресія (MLR)
- Поліноміальна регресія (3-го та 11-го порядку)
- Pipeline: StandardScaler → PolynomialFeatures → LinearRegression
- Порівняння моделей за R² та MSE

Ноутбук: `Lab3_Model_Development.ipynb`

Бібліотеки: pandas, numpy, matplotlib, seaborn, scikit-learn
